# What is this?
Fluid Tech is a WIP Idea for Empire at War that focuses on a more dynamic Tech Level, by using structures and story elements to guide what can be built and what is locked.

# DISCLAMER
This uses AlyMar's UFoCP as a base, cuz i was too lazy to extract the game's MEG files, Source code for their mod can be found here: https://github.com/AlyMar1994/UFoCP and the Steam Page Here: https://steamcommunity.com/sharedfiles/filedetails/?id=1548018187
